## Различия платформ

* MapKit Android заменён Leaflet 1.9.4 с подложкой OpenStreetMap: API-ключ Android не подходит для веб. Интерфейс выбора мест и набор данных сохранены. Тайлы не скачиваются массово и не предкэшируются service worker.
* 3D-геометрия вычисляется оригинальным Kotlin-кодом и экспортируется; браузер рисует её Canvas 2D вместо Android Canvas. Пиксельное освещение может отличаться.
* Разрешениями сайта управляет браузер, а не Android Settings. Геолокация запрашивается только кнопкой посетителя; координаты не сохраняются.
* Реальный вход через Яндекс ID требует настройки OAuth для веб-домена, допустимого redirect и серверной сессии. В приложении также нет общего бэкенда синхронизации. Локальный выбор документов явно не выдаётся за серверное подтверждение аккаунта.
* Фоновая синхронизация, собственные оплаты/запись и push-уведомления не добавлены: в текущем Android они также не подключены.

## Обновление из Android

Из веб-папки: `./scripts/export-android.ps1 -AndroidRoot 'C:/path/to/MyCar2'`. Нужны уже закэшированные Kotlin/Gson и Java, как указано в скрипте. Сборка сайта использует уже сгенерированные файлы, Java на хостинге не требуется.

`node scripts/check-android-parity.mjs C:/path/to/MyCar2` проверяет SHA-256 24 исходников, из которых сделан экспорт. После изменения исходников повторить экспорт, проверку, `npm test`, `npm run build`.

Новые модули `full*.js` добавляют текущие сценарии поверх прежнего совместимого хранилища. Ключ гаража и версия JSON сохранены; сервисный worker обновляется с явным уведомлением после установки новой версии. Проверка соответствия не читает Android SharedPreferences и не переносит чужие данные.

## Проверки этой версии

Unit-проверки: полнота экспортированных материалов, связи деталей/статей/услуг, 3D-геометрия и проекция, попадание в полигоны, отсутствие потерь точек в кластерах, русские псевдонимы, текущие версии согласий, отсутствие предвыбранных необязательных решений, сохранение гаража и миграция чек-листа.

В браузере: главная, вращение 32° → 67°, поиск АКБ, увеличение фотографии, фильтр штрафстоянок и карточка места, перелистывание 1/17 → 2/17, 63 индикатора и детальный экран, шесть исходно неотмеченных согласий и выключенная кнопка подтверждения, выбор «Киа Рио» через каталог и внутренние услуги машины. Согласия за пользователя не принимались, реальные звонки/записи/маршруты/запрос геолокации не выполнялись.

Проверено обновление установленной оболочки: уведомление «Доступна новая версия Юркар» → «Обновить» → новая версия, тестовый гараж сохранён. 03.11.2026 подтверждены актуальные DNS-записи REG.RU; в GitHub Pages повторным сохранением домена перезапущен выпуск сертификата, DNS check successful, включён Enforce HTTPS.
